# 🛒 Shopping Cart App (React)

A simple and clean Shopping Cart built with **React JS**. Users can view products, add them to a cart, and see the cart update in real time with price and quantity calculations.

---

## 🚀 Features

- 🧩 View products with name, image & price
- ➕ Add and remove items from cart
- 🔢 Quantity and total price calculation
- ⚛️ Built using React functional components
